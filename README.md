## ✨ What is HaptiX?

**HaptiX** explores the interaction between **visual content and tactile feedback**.

The platform synchronizes a video with a timestamped haptic timeline so that events such as impacts, motion, acceleration, engine rumble, and cinematic transitions can be experienced through the device's vibration system.

The current Android implementation focuses on **precise temporal synchronization**, controlled haptic rendering, user feedback collection, and device-performance monitoring.

## 🎯 Core Features

| Feature | Description |
|---|---|
| 🎞️ Synchronized Playback | Video and haptic events follow the same playback timeline |
| 📍 Haptic Playline | Visual markers show where tactile events occur in the video |
| ⏯️ Full Controls | Play, pause, resume, seek, rewind and fast-forward |
| 📳 Haptic Toggle | Enable or disable tactile feedback during playback |
| 🧪 Research Feedback | Structured 1–5 participant feedback collection |
| 👤 Participant Profile | Research-oriented participant information |
| 📈 Performance Monitoring | Periodic CPU, GPU and temperature measurements |
| 🎬 Video Ingestion | Architecture supports curated and dynamically processed video sources |
| 🔬 Reproducible Processing | Source analysis and validation scripts are included |
